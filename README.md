# My Expenses - Personal expense dashboard

Open `index.html` in your browser (or use the VS Code "Live Server" extension).

- `index.html`: page structure
- `styles.css`: styles (colors are CSS variables; light/dark mode is automatic)
- `app.js`: state, form, filters and charts (Chart.js via CDN)

Change `LOCALE` and `CURRENCY` at the top of `app.js` to switch formats (e.g. `en-GB` / `GBP`).
Data is stored in the browser's localStorage.
